# Task Generate

**Автор:** [Злата Боровских]

**Описание:**
Приложение для генерации случайных задач с фильтрацией по типу, сохранением истории и добавлением новых задач. Использует библиотеку 'random' для выбора задачи, 'json' для сохранении истории и 'tkinter' для GUI.

**Функционал:**
- Генерация случайной задачи по нажатию кнопки.
- Отображении истории сгенерированных задач.
- Фильтрация задач по типу (учёба, отдых, работа, спорт)
- Добавление новых задач с указанием типа.
- Сохранении истории в файл 'history.json'.
- Проверка на пустой ввод при добавлении задачи.

**Примеры использования:**
1. Нажмите "Сгенерировать задачу" - появится случайная задача.
2. Используйте фильтр, чтобы видеть только задачи определённого типа.
3. Добавьте новую задачу через поле ввода и выберите её тип.
4. История задач сохраняется даже после закрытия приложения.

**Техологии:**
- Python 3.x
- Библиотека 'thinker' (графический интерфейс)
- 'random' (генерация случайных задач)
- 'json' (сохранении истории)
- 'Git' (контроль версий)
